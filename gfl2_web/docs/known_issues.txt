#1  remold.js: doll editor dropdown broken (d.name on array)
STATUS:   RESOLVED
SEVERITY: critical
Filed:    2026-06-07
Fixed:    2026-06-07

DESCRIPTION:
  js/remold.js line 14:
    let dollNames = ["__", ...DOLL_MASTER.map(d => d.name).sort()];
  DOLL_MASTER entries are plain arrays, not objects.  `d.name` evaluates
  to undefined for every entry.  The inline doll reassignment dropdown
  therefore shows "__" followed by 47 blank/undefined options.  Doll
  assignment editing is completely non-functional.

FIX:
  Changed `d.name` to `d[5]` (consistent with unit.js which already uses d[5]).

#9  extract_gfl2.py fails after Google Sheet tab rename/reorg
STATUS:   RESOLVED
SEVERITY: high
Filed:    2026-08-29
Fixed:    2026-08-29

DESCRIPTION:
  After the source sheet was updated with new doll tabs, extraction broke
  in two ways:
  1. fetch_values() stripped the sheet name before requesting it
     (sheet_name.strip()), but ~33/69 tabs now carry a trailing space in
     their real title (e.g. "Groza "), and one tab has a colon ("Nemesis:
     Gnosis"). The stripped/unquoted name no longer matches the tab, so
     Sheets API returned 400 "Unable to parse range" for every affected
     doll — extraction failed on the very first tab.
  2. Once fixed, "Nemesis: Gnosis" crashed `(ASSETS_DIR / key).mkdir(...)`
     with WinError 267 — ':' is illegal in a Windows path/directory name.
  3. Liushih's Neural Helix section is relabeled "Digimind Helix" in its
     tab, so find_section(rows, "Neural Helix") returned None and the doll
     failed with MISSING SECTION.

FIX:
  - fetch_values() now single-quotes the sheet name and is called with the
    tab's verbatim (unstripped) title.
  - Added safe_path_name() to sanitize doll names used in filesystem paths
    (assets/{doll}/ dirs and icon path strings).
  - Added find_helix_section(), matching any section header ending in
    "Helix" instead of the exact "Neural Helix" string.
  Re-ran the extractor: all 64/64 doll tabs now parse cleanly (up from 28
  previously committed).

      Basti, Cheyanne, Eagletta, Harpsy, Lainie, Liushih, Loreley, Mityl,
      "Nemesis: Gnosis", Welrod — these ammo types split across two
      weapon types (SMG/HG, SR/LMG) in the existing roster, so the
      correct weapon can't be inferred.

FIX:
  Verify actual rarity and weapon type per doll (e.g. against a wiki or
  in-game) and replace the placeholder values in data/master_doll.js.
